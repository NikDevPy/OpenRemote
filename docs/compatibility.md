# Совместимость: что установлено на 7 ноября 2026 года

## Решение

**Основную разработку не начинать до end-to-end теста личного Plus.**
Нет оснований объявлять ни гарантированную доступность универсального shell,
ни категорический запрет по одному имени `execute_command`.

| Вопрос | Статус | Основание |
|---|---|---|
| Собственный MCP может объявлять read/write-инструменты | Подтверждено документацией | [1] |
| Обязательны search/fetch | Нет, по документации | [1] |
| Публикация обязательна для подключения своего MCP | Не требуется описанным частным путём; политики аккаунта применяются | [1], [2] |
| Plus допускает эти три инструмента в обычном «Чат» | **Не проверено в аккаунте** | Документация [1] не содержит явной таблицы Plus |
| Любой execute_command допускается без ограничений | **Не подтверждено** | Write-подтверждения и политики применяются [1] |
| Успешный локальный MCP = проверенный Plus | Нет | Разные клиенты и границы доступа |
| Частный сервер без публичного HTTPS | Документирован Secure MCP Tunnel, доступ нужно проверить | [2], [3] |
| Собственный Tailscale IP напрямую доступен hosted ChatGPT | Не подтверждено | Частная tailnet сама не предоставляет доступ облачному клиенту |
| ZIP/GitHub гарантирует установку каждым Plus в обычном web-чате | Не подтверждено | Локальные marketplaces зависят от поверхности [4] |
| Общедоступный каталог | Review → approval → отдельное действие Publish | [5] |
| Каждый пользователь публичного плагина вводит свой endpoint | Не обещать: template URLs ограничены trusted developers | [6] |

В поиске встречаются старые страницы Help Center про Business/Enterprise/Edu
и старые копии Developer Mode с иными списками тарифов. Они не используются
как доказательство текущего запрета или разрешения Plus. Текущая страница [1]
документирует read/write и account/workspace restrictions, но не разрешает
вопрос конкретного аккаунта. Нужен наблюдаемый результат, а не догадка о rollout.

## Что выполнено в этой сессии

- GitHub подтвердил пустой репозиторий и право push.
- SSH сначала отказал из-за системного ssh_config, затем с `-F /dev/null`
  показал ошибку DNS github.com. Системные настройки не менялись.
- Используется GitHub connector, без подмены SSH-проверки утверждением об успехе.
- Реализованы три инструмента; запуск дочернего процесса и создание квитанции
  проверяются автоматическими тестами через MCP.
- Доступный браузер открыл ChatGPT Plugins без авторизованной сессии.
  Это блокер проверки аккаунта; не свидетельство ограничения Plus.
- Нет tunnel ID/runtime key, установленного подключения OpenRemote в ChatGPT,
  серверного OAuth или публичного HTTPS deployment.
- Публикация и распространение реальным вторым Plus-аккаунтом не выполнены.

## Как это влияет на архитектуру

До результатов сохраняется небольшое переносимое ядро MCP без брокера.
Если личный Direct MCP проходит тест на Plus, это кандидат для первого режима.
Если частное подключение/распространение не проходит, публичный каталог —
отдельная проверка; единый endpoint может потребовать опциональный broker.
Нельзя делать его обязательным заранее или обещать, что review одобрит
универсальное удалённое управление. Конкретные операции могут потребовать
подтверждения или получить отказ независимо от тарифа.

   интерфейс подключения, схемы аутентификации, аннотации и подтверждения.
2. https://developers.openai.com/plugins/deploy/connect-chatgpt — тест endpoint,

3. https://developers.openai.com/api/docs/guides/secure-mcp-tunnels — private
   stdio/HTTP, Platform key, tunnel permissions и workspace associations.
4. https://developers.openai.com/plugins/build/plugins — portable manifests,
   local/repo marketplaces; доступность может различаться по клиентам.
5. https://developers.openai.com/plugins/deploy/submission — identity/domain
   verification, стабильный публичный HTTPS, 5 positive/3 negative cases,
   dedicated reviewer account, видео, approval и публикация.
6. https://developers.openai.com/plugins/deploy/app-review — universal endpoint,
   template URLs только для trusted developers с established relationship.
7. https://py.sdk.modelcontextprotocol.io/v1/ — применённый SDK v1,
   maintenance-статус, наличие stable v2.
