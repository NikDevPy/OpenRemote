# OpenRemote v0.3.1 — draft release notes

**Stage:** early-access Linux release candidate.
**License:** MIT.

## Included

- Private ChatGPT integration using OpenAI Secure MCP Tunnel.
- A single gateway controlling its local Linux device or registered Linux SSH
  peers through Tailscale or trusted SSH.
- Workspaces with text read/create and SHA-256 checked replacement.
- Named command policies with local one-time privileged-command approvals.
- Owner-enabled dynamic argv execution under the agent's Linux account.
- Viewer, operator and admin roles, with SQLite audit.

## Verified

- Linux x86_64: automated suite and direct ChatGPT tool calls.
- Linux ARM64: actual remote MCP calls through the gateway.
- **Windows: NOT TESTED / UNSUPPORTED.**
- **macOS: NOT TESTED / UNSUPPORTED.**

## Known limitations

No independent per-user authorization. Dynamic argv can reach any files the
OS account can access; workspaces do not isolate subprocesses. No durable PTY
sessions or large-file streaming yet. ChatGPT and Secure MCP Tunnel impose
additional request and safety controls.
