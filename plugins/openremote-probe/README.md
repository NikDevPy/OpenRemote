# Черновик пакета

`plugin.json` — переносимый манифест, `mcp.template.json` — заготовка
удалённого подключения, намеренно не названа `mcp.json`, чтобы её нельзя
было принять за рабочую интеграцию. OAuth-сервер и реальный URL ещё нужны.
Секреты в пакет не добавлять. Созданного ChatGPT plugin ID пока нет.

Для первого частного опыта используйте Create as a plugin через Secure MCP
Tunnel, как описано в корневом README. Этот файл/каталог не устанавливает
плагин в аккаунте ChatGPT и не доказывает доступность Plus.

Для публичного ZIP после выбора транспорта: реальный `mcp.json`, иконка,
подтверждённые website/support/privacy/terms URLs, данные издателя,
пять положительных и три отрицательных review-сценария, видео и test account.
Не подставлять фиктивные политику конфиденциальности или условия.
